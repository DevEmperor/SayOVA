SayOVA（Orb Voice Assistant）能让您的 Wear OS 手表变成真正的对话伙伴。抬起手腕，自然开口，想打断就打断——一边听回答，一边在手表上同步阅读文字。

<b>不是指令，而是真正的对话</b>
SayOVA 会将您的语音实时传送给语音到语音模型（Google Gemini Live 或 OpenAI Realtime），回答边生成边播放。就像和人聊天一样，直接开口就能打断它，也可以点按光球。

<b>边听边看</b>
对话时，双方说的话都会显示在屏幕上。回答中您已听到的部分会亮起，其余部分仍显示为暗色，让您随时知道听到了哪里。

<b>腕上的口译员</b>
从 21 种语言中选择两种，把手表放在您和对方之间。SayOVA 会把说的话用另一种语言说出来，并以文字显示双方的内容。

<b>该安静时就安静</b>
在上课、开会，或身处安静的房间？点按一下即可关闭 SayOVA 的声音，回答将以文字显示。

<b>帮您把事办好</b>
让 SayOVA 设置计时器或闹钟（可设为每个工作日重复）、保存笔记、查看电量，或上网搜索新闻、天气、营业时间等各种最新信息。

<b>在手机上准备好</b>
“用 WhatsApp 告诉丽娜我会晚到十分钟”“把周二下午三点看牙医加到日历里”“步行去车站的路线”——SayOVA 会先把消息读给您听，您确认后，内容就会在手机上您常用的应用中准备就绪，只等您发送、添加或开始导航。SayOVA 绝不会以您的名义发送任何内容。

<b>了解您的手表——仅在您提问时</b>
“这里天气怎么样？”“我的心率是多少？”“今天走了多少步？”“今天下午有什么安排？”“闹钟几点响？”“暂停音乐”“给丽娜打电话”“打开手电筒”——只有在您授权一次后，SayOVA 才会使用您的位置、天气、心率、步数、日历、气压、下一个闹钟、音乐、联系人、应用或通知，并且仅用于回答当前问题，使用期间会显示图标。只有在您确认姓名和号码后，才会拨打电话。

<b>只记住您要求的事</b>
说一句“记住我吃素”，之后的每次对话都会知道。只保存您要求记住的内容，且仅存储在手表上；每一条都可以在设置中查看或删除。

<b>您的服务商、您的密钥、您的数据</b>
SayOVA 使用您自己的 Google Gemini（每分钟约 1 美分起，提供免费额度）或 OpenAI API 密钥。您的语音从手表直接发送给服务商——中间没有 SayOVA 服务器，无需账号，没有跟踪，也没有广告。

<b>先听一听</b>
在您进行任何设置之前，SayOVA 会在手表上播放一段示例对话，问答双方都有语音。简短的导览会介绍其余功能。

<b>一分钟完成设置</b>
用手机扫描手表上的二维码，粘贴密钥，核对六位数代码，就完成了。密钥会在您的浏览器中加密，仅供您的手表使用——无需配套应用，也不用在小小的键盘上打字。

<b>为手表而生</b>
• 对话期间使用 WLAN 或 LTE，音频流畅不卡顿
• 屏幕关闭后仍可继续对话，表盘上会显示图标
• 功能块和表盘复杂功能，点按一下即可开始对话
• 支持蓝牙耳机
• 个性（友好、简洁、详细、导师、语言伙伴或自定义）、40 种可先试听再选择的声音、回答语言
• 实时费用估算、用量统计和每月预算
• 历史记录仅存储在手表上，保留多久由您决定

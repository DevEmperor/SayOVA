SayOVA(Orb Voice Assistant)는 Wear OS 시계를 진짜 대화 상대로 바꿔 줍니다. 손목을 들고 자연스럽게 말하세요. 원할 때 언제든 말을 끊을 수 있고, 답변은 귀로 들으면서 시계 화면에서 글로도 따라 읽을 수 있습니다.

<b>명령어가 아닌 진짜 대화</b>
SayOVA는 사용자의 음성을 음성 대 음성 모델인 Google Gemini Live 또는 OpenAI Realtime에 실시간으로 전송하고, 답변이 생성되는 대로 바로 들려줍니다. 사람과 대화할 때처럼 중간에 말하면 답변이 멈추고, 오브를 탭해도 됩니다.

<b>듣고, 읽고</b>
대화하는 동안 양쪽의 말이 모두 화면에 표시됩니다. 답변 중 이미 들은 부분은 밝게, 나머지는 아직 흐리게 보여서 어디까지 들었는지 놓치지 않습니다.

<b>손목 위의 통역사</b>
21개 언어 중 두 가지를 고르고 시계를 대화 상대와 나 사이에 두세요. SayOVA가 모든 말을 다른 언어로 전하고, 양쪽의 말을 텍스트로도 보여 줍니다.

<b>조용해야 할 때는 조용하게</b>
강의나 회의 중이거나 조용한 방에 있나요? 한 번 탭하면 SayOVA의 음성이 꺼지고 답변이 텍스트로 표시됩니다.

<b>할 일도 척척</b>
타이머나 알람 설정(원하면 평일마다 반복), 메모 저장, 배터리 확인을 SayOVA에게 부탁하세요. 뉴스, 날씨, 영업시간 등 최신 정보는 웹에서 검색해 알려 줍니다.

<b>휴대폰에서 미리 준비</b>
“민지한테 WhatsApp으로 10분 늦는다고 보내 줘”, “화요일 오후 3시에 치과 일정 캘린더에 넣어 줘”, “역까지 걸어가는 길 알려 줘”라고 말하면 SayOVA가 메시지를 다시 읽어 줍니다. “응”이라고 답하면 휴대폰에서 평소 쓰는 앱에 내용이 준비되어, 보내기·추가·시작만 누르면 됩니다. SayOVA가 사용자 이름으로 무언가를 보내는 일은 절대 없습니다.

<b>내 시계를 잘 아는 비서 — 물어볼 때만</b>
“여기 날씨 어때?”, “내 심박수는?”, “오늘 몇 걸음 걸었어?”, “오늘 오후 일정 뭐 있어?”, “알람 언제 울려?”, “음악 일시정지해 줘”, “민지한테 전화해 줘”, “손전등 앱 열어 줘” 같은 질문과 부탁에도 답합니다. SayOVA는 위치, 날씨, 심박수, 걸음 수, 캘린더, 기압, 다음 알람, 음악, 연락처, 앱, 알림을 한 번 허용한 뒤 해당 질문에만 사용하며, 사용하는 동안 아이콘을 표시합니다. 전화는 이름과 번호를 확인한 뒤에만 겁니다.

<b>부탁한 것만 기억합니다</b>
“나는 채식주의자라고 기억해 줘”라고 말하면 이후 모든 대화에서 이를 기억합니다. 부탁한 내용만 시계에 저장되며, 기억한 항목은 설정에서 모두 확인하거나 삭제할 수 있습니다.

<b>내 제공업체, 내 키, 내 데이터</b>
SayOVA는 사용자 본인의 Google Gemini API 키(분당 약 1센트부터, 무료 등급 제공) 또는 OpenAI API 키로 작동합니다. 음성은 시계에서 제공업체로 바로 전송됩니다. 중간에 SayOVA 서버가 없고, 계정도, 추적도, 광고도 없습니다.

<b>먼저 들어 보세요</b>
설정을 시작하기 전에 SayOVA가 시계에서 예시 대화를 재생합니다. 질문과 답변 모두 음성으로 들을 수 있습니다. 나머지는 짧은 투어에서 소개합니다.

<b>1분이면 설정 완료</b>
시계에 표시된 QR 코드를 휴대전화로 스캔하고, 키를 붙여 넣고, 6자리 코드를 비교하면 끝입니다. 키는 브라우저에서 내 시계 전용으로 암호화됩니다. 컴패니언 앱도, 작은 키보드로 입력할 필요도 없습니다.

<b>시계를 위해 만든 앱</b>
• 대화 중에는 Wi-Fi 또는 LTE를 사용해 매끄러운 오디오
• 화면이 꺼져도 대화 유지, 워치 페이스에 아이콘 표시
• 탭 한 번으로 대화를 시작하는 타일과 컴플리케이션
• 블루투스 헤드폰 지원
• 성격(친근함, 간결함, 자세히, 튜터, 언어 파트너, 사용자 지정), 들어 보고 고를 수 있는 40가지 음성, 답변 언어
• 실시간 비용 추정, 사용량 통계, 월 예산
• 기록은 시계에만, 원하는 기간 동안 보관

<b>오픈소스</b>
SayOVA는 Apache 라이선스 2.0에 따른 오픈소스입니다. 음성과 키를 어떻게 다루는지 코드로 정확히 확인할 수 있습니다: github.com/DevEmperor/SayOVA — 모든 기능은 가이드에서 그림과 함께 단계별로 설명합니다: github.com/DevEmperor/SayOVA/wiki

마이크가 있는 Wear OS 3 이상 시계와 Google Gemini 또는 OpenAI의 API 키가 필요합니다. 사용 요금은 제공업체가 청구합니다. Gemini API는 만 18세 이상 사용자를 대상으로 합니다.
